# Peer Review — бриф для агента

Платформа peer-review студенческих работ: студенты загружают работы, система анонимно распределяет их на рецензирование по рубрике, преподаватель видит статистику, конфликты оценок и «халтурные» рецензии.
Требования — `docs/SPEC.md` (источник истины). Архитектура — `docs/ARCHITECTURE.md`. Термины — `docs/GLOSSARY.md`. Как устроен процесс — `docs/WORKFLOW.md`.

Стек: Python 3.13, Django 5.2, HTMX, шаблоны Django, PostgreSQL (локально без Docker — SQLite), uv.

## Команды
| Команда | Что делает |
|---|---|
| `make check` | **Definition of Done**: lint + types + migrations-check + тесты + покрытие ≥ 85% |
| `make check-fast` | быстрая проверка (её же запускает Stop-хук) |
| `make test` / `make test-fast` | тесты без e2e / быстрые со стопом на первой ошибке |
| `uv run pytest path::test -q` | один тест |
| `make e2e` | браузерные тесты Playwright |
| `make run` / `make seed` | dev-сервер :8000 / демо-данные (учётки в `apps/core/management/commands/seed_demo.py`) |
| `make makemigrations` | новые миграции (руками миграции не пишем) |
| `make format` | автоформат |

Если `uv` не в PATH: `make <цель> UV=~/Library/Python/3.13/bin/uv`.

## Карта кода
- `config/` — settings (`base`/`dev`/`test`/`prod`), urls.
- `apps/core` — общее: базовые модели, healthz, seed_demo.
- `apps/accounts` — пользователи и роли (student/teacher), права доступа.
- `apps/courses` — курсы, группы, запись на курс.
- `apps/assignments` — задания, рубрики (критерии, шкалы), дедлайны.
- `apps/submissions` — загрузка работ, соавторы.
- `apps/reviews` — назначения на рецензию, рецензии, оценки по критериям.
- `apps/allocation` — **чистый Python**: алгоритм распределения (см. его `CLAUDE.md`).
- `apps/quality` — детекторы халтурных рецензий; ядро — чистый Python (см. его `CLAUDE.md`).
- `apps/analytics` — статистика и конфликты оценок.
- `apps/notifications` — напоминания о дедлайнах.
- `tests/{unit,integration,property,e2e}` + `tests/factories.py`.

Правило слоёв: views тонкие → `services.py` (бизнес-логика, транзакции) → модели. Алгоритмы — в чистых модулях без импорта Django.

## Инварианты домена (нарушение = BLOCKER)
1. **Анонимность**: рецензент не видит автора, автор не видит рецензента (преподаватель видит всё). Наружу — только `public_code`, не id и не username. Файл работы отдаётся под нейтральным именем.
2. **Распределение**: никто не рецензирует свою работу; нет взаимных пар (A→B и B→A); соавторы не рецензируют друг друга и одну и ту же работу; у каждой работы ровно `k` рецензентов; нагрузка рецензентов отличается не больше чем на 1; при невыполнимости — понятная ошибка, а не падение.
3. **Дедлайны**: после дедлайна сдачи работу не изменить, после дедлайна рецензий рецензию не изменить. Проверка — на сервере.
4. **Права**: каждый view проверяет роль и принадлежность к курсу (без IDOR).

## Как работать над задачей
Всегда через `/task T-xxx` (см. `.claude/skills/task/SKILL.md`): ветка → план → **тесты сначала** (test-writer) → реализация (implementer) → `make check` → ревью (code-reviewer + anonymity-auditor) → e2e → PROGRESS.md + agent-log → коммит.
Новая задача — `/new-task`. Модель — `/model`. Ревью — `/review`.

## Ограничители (хуки в `.claude/settings.json`)
- Stop-хук запускает `make check-fast` и не даёт закончить ход с красными проверками.
- После правки `*.py` автоматически работает ruff; после правки `models.py` проверяется, нужна ли миграция.
- Заблокировано: правка `.env*`, закоммиченных миграций, харнесса (`.claude/settings.json`, `.claude/hooks/`), `tests/**` в режиме protect-tests, коммит в `main`, `--no-verify`, force-push, отключение покрытия.

## Конвенции
- Ветки `feat/T-xxx-slug`, `fix/…`; коммиты в стиле Conventional Commits (`feat(T-012): …`), на русском.
- Код и идентификаторы — на английском; `verbose_name`, тексты UI, docstring и документация — на русском.
- Новая зависимость — только с согласия человека (`uv add` требует подтверждения).

## Никогда
- Не ослабляй и не удаляй тесты, чтобы стало зелёным. Если тест неверен — скажи человеку.
- Не говори «готово», если `make check` не запускался или упал. Показывай вывод.
- Не пушь в `main` и не пушь без подтверждения.
