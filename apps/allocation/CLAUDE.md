# apps/allocation — алгоритм распределения работ на рецензирование

**Чистый Python, без импорта Django.** Модуль получает простые структуры данных и возвращает назначения. Сохранение в БД — в `apps/reviews/services.py`. mypy работает здесь в strict-режиме, покрытие ≥ 95%.

## Контракт (целевой)
```python
@dataclass(frozen=True)
class Work:            # одна сданная работа
    id: str
    authors: frozenset[str]          # один автор или команда

def allocate(
    works: Sequence[Work],
    reviewers: Sequence[str],        # обычно = все авторы
    k: int,                          # рецензий на работу
    forbidden: Set[tuple[str, str]] = frozenset(),  # (reviewer, work_id), напр. «уже рецензировал»
    seed: int = 0,
) -> Allocation                      # dict[work_id, list[reviewer]]
# raises InfeasibleAllocation(reason: str)
```

## Инварианты (каждый покрыт property-тестом в `tests/property/test_allocation_props.py`)
1. Нет самоназначения: рецензент не входит в `authors` своей работы.
2. Нет взаимности: если A рецензирует работу, где автор B, то B не рецензирует работу, где автор A.
3. Соавторы не рецензируют одну и ту же работу.
4. У каждой работы ровно `k` различных рецензентов.
5. Нагрузка сбалансирована: max − min ≤ 1.
6. `forbidden` соблюдается.
7. Детерминизм: тот же `seed` даёт тот же результат; разные seed — разные перестановки.
8. Невыполнимый вход → `InfeasibleAllocation` с объяснением, а не падение и не зависание.

## Алгоритмы
- **Циркулянтный** (индивидуальные работы, без запретов): перемешать авторов по seed; автор `i` рецензирует работы `(i+s) mod n` для `s ∈ S`, где `S ⊂ {1..⌊(n−1)/2⌋}`, |S| = k. Взаимности нет, потому что `n−s ∉ S`. Выполнимо при `k ≤ ⌊(n−1)/2⌋`.
- **Потоковый** (общий случай: команды, запреты): двудольный граф рецензенты → работы, max-flow с ёмкостями (k на работу, ⌈nk/m⌉ на рецензента); взаимные пары устраняются локальными обменами, при неудаче — перезапуск с новым seed (ограниченное число попыток).
- Сравнение алгоритмов (время, баланс) — `tests/property/` + бенчмарк → раздел записки.

Изменения алгоритма — только вместе с ADR в `docs/adr/`.
