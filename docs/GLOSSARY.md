# Глоссарий

| Термин | Код | Значение |
|---|---|---|
| Курс | `Course` | дисциплина, в которую записаны студенты |
| Задание | `Assignment` | лабораторная или эссе с дедлайнами и рубрикой |
| Рубрика | `Rubric` | набор критериев оценивания задания |
| Критерий | `Criterion` | аспект оценки (например, «Корректность»), с весом |
| Шкала / уровень | `ScaleLevel` | допустимые баллы критерия с описанием каждого уровня |
| Работа | `Submission` | то, что сдал автор или команда по заданию |
| Публичный код | `public_code` | анонимный идентификатор работы, видимый рецензенту |
| Автор / соавторы | `Submission.authors` | один студент или команда |
| Назначение | `ReviewAssignment` | пара «рецензент — работа», результат распределения |
| Распределение | `allocate()`, `AllocationRun` | алгоритм назначения рецензентов и его запуск |
| k | `Assignment.reviews_per_submission` | сколько рецензий получает каждая работа |
| Взаимная пара | — | A рецензирует B и B рецензирует A — запрещено |
| Рецензия | `Review` | оценки по критериям и комментарий |
| Флаг халтуры | `QualityFlag` | срабатывание детектора на рецензии |
| Конфликт оценок | — | слишком большой разброс оценок рецензентов по одной работе |
| Итоговая оценка | — | медиана взвешенных баллов, может быть переопределена преподавателем |
