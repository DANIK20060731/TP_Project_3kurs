# ADR-0001: Монолит Django + HTMX

- Статус: принято
- Дата: 2026-10-22

## Контекст
Курсовая для двух человек с ограниченным сроком. Работа ведётся с помощью кодингового агента. Нужны: формы (рубрики, рецензии), права доступа, админка, фоновые напоминания.

## Решение
Монолит на Django 5.2 с серверным рендерингом, интерактивность — через HTMX (автосохранение черновика, частичное обновление списков). Отдельного SPA нет.

## Последствия
+ Одна кодовая база и один язык: агенту проще держать контекст, тесты единообразны (pytest-django).
+ Админка, формы, CSRF и аутентификация — из коробки.
+ e2e через pytest-playwright с фикстурой `live_server` — без отдельного запуска фронтенда.
− Меньше «современного фронтенда» в отчёте. Компенсируется доменным ядром (алгоритм, детекторы) и харнессом.
