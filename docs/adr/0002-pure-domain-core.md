# ADR-0002: Чистое доменное ядро для распределения и детекторов

- Статус: принято
- Дата: 2026-10-22

## Контекст
Алгоритм распределения и детекторы халтуры — самая сложная и самая проверяемая часть темы. Их корректность выражается инвариантами («нет взаимных пар» и т. п.), которые удобно проверять property-based тестами на тысячах случайных входов.

## Решение
`apps/allocation` и `apps/quality/detectors` — чистый Python без импорта Django: на вход dataclass-ы, на выход dataclass-ы или исключения. Связь с БД — в `services.py` соответствующих приложений. mypy strict, покрытие ≥ 95%.

## Последствия
+ Property-тесты hypothesis работают без БД, за миллисекунды — агент получает обратную связь мгновенно.
+ Алгоритмы можно сравнивать и бенчмаркать отдельно (раздел записки).
− Нужен слой преобразования модели ↔ dataclass.
