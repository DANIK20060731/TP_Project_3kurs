# ADR-0003: Харнесс кодингового агента

- Статус: принято
- Дата: 2026-10-22

## Контекст
Условие курсовой — разработка с помощью кодингового агента. Типичные провалы агентов: объявляют «готово» без проверки; меняют тесты под код; забывают миграции; правят то, что трогать нельзя; проверяют свою же работу.

## Решение
Детерминированный харнесс поверх Claude Code (подробно — `docs/WORKFLOW.md`):
- `make check` как единый Definition of Done;
- Stop-хук запускает проверки и не даёт завершить ход с красными результатами;
- PreToolUse-хуки защищают секреты, миграции, харнесс и тесты (режим protect-tests);
- разделение субагентов: тесты пишет test-writer, код — implementer, проверяют read-only ревьюеры;
- единый процесс `/task` и журнал `docs/agent-log/`.

## Последствия
+ Ошибки агента ловятся автоматически, а не на защите.
+ Журнал даёт фактический материал для отчёта.
− Stop-хук добавляет 10–20 с к каждому ходу с изменениями кода.
− Хуки на Python требуют `python3` в PATH.
