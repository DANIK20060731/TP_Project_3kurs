# ADR-0004. Алгоритмы распределения рецензий

- Статус: принято
- Дата: 2026-11-19
- Требования: FR-4.2–FR-4.4, NFR-2, NFR-3

## Контекст

Составы команд и запреты на отдельные назначения меняют набор допустимых
рецензентов. Баланс считается по всем сдавшим студентам, включая тех, у кого
нет назначений. При пяти работах, шести авторах и одной рецензии на работу
допустимы нагрузки 0 и 1. Условия взаимности и участия соавторов проверяются
для пары работ целиком.

## Решение

Для индивидуальных работ без запретов используется циркулянт из T-006.
Для команд и запретов используется целочисленный поток с ограничениями.

Пусть нужно назначить `n × k` рецензий между `m` студентами. Частное `q`
и остаток `r` от деления `n × k` на `m` задают нагрузку. Поток даёт каждому
рецензенту `q` основных назначений и допускает одно дополнительное.
Общая ёмкость дополнительных назначений равна `r`. Полный поток насыщает
суммарную ёмкость, поэтому ровно `r` студентов получают `q + 1` назначение,
остальные получают `q`. Через пару «команда-рецензент — проверяемая работа»
проходит максимум одна единица потока. Самоназначения и запрещённые пары
отсутствуют в графе.

Для индивидуального задания, в котором число допустимых неориентированных
пар равно `n × k`, нужны все пары. Каждая работа должна иметь степень `2k`,
поскольку её автор получит `k` назначений и его работа получит `k` рецензий.
Отдельный поток направляет каждую пару в одну из разрешённых целевых работ.
Если каждая работа получает ровно `k` входящих назначений, степень `2k`
даёт столько же исходящих.

В остальных случаях пробуем до трёх ориентаций пар по случайному порядку
работ на круге. Если полный поток содержит взаимную пару, любое допустимое
распределение исключает хотя бы одно из двух направлений. Проверка обоих
случаев сохраняет полноту до лимита. При `c` допустимых назначениях отдельных
рецензентов бюджет составляет `min(128, max(2, 200_000 // c))` запусков потока.
После исчерпания бюджета преподаватель получает сообщение о незавершённом
поиске и может изменить число рецензий или пересмотреть ограничения.

## Воспроизводимость и анонимность

Порядок исходных списков не влияет на результат. Параметр `seed` и готовый
граф назначений доступны только преподавателю на уровне интеграции T-008.
Коды работ в диагностике предназначены для сообщения преподавателю.

В циркулянте сдвиги коммутируют. Два последовательных назначения со
сдвигами `s₁` и `s₂` ведут к той же позиции при обратном порядке сдвигов.
Поэтому участники, которые обмениваются известными назначениями, могут
вывести дополнительные связи. Для курсовой этот риск принят в T-006.
Назначения потокового алгоритма общей формуле сдвигов не подчиняются.

## Замеры

300 работ, `k=3`, 20 запусков с seed от 0 до 19 для каждого входа.
Замер вызова `allocate` без построения входных данных и без Django.
Среда замера — macOS x86_64, Python 3.13.15.

| Работы и ограничения | Алгоритм | Медиана, с | Максимум, с | Нагрузка |
|---|---|---:|---:|---:|
| 300 индивидуальных, без запретов | Циркулянт | 0,001 | 0,002 | 3 |
| 300 индивидуальных, один запрет | Поток | 0,407 | 0,805 | 3 |
| 270 индивидуальных и 30 пар, один запрет | Поток | 0,515 | 0,772 | 2–3 |
| 300 индивидуальных, допустимы только смещения ±1, ±2, ±3 по кругу | Поток с ориентацией всех пар | 0,122 | 0,190 | 3 |

Последний вход закреплён регрессией. Произвольные запреты и составы команд
могут привести к исчерпанию бюджета поиска.
