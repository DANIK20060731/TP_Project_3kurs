# ADR-0005: Периодический запуск напоминаний

- Статус: принято для T-014
- Дата: 2026-11-18

## Контекст

Напоминания о сдаче нужно регулярно отправлять через почтовый backend Django. Команда `send_reminders` вычисляет получателей по текущим дедлайнам и записывает отправки в БД.

## Решение

В окружении развёртывания запускать `uv run python manage.py send_reminders` через cron каждые пять минут с рабочей директорией проекта и его настройками Django, БД и почты. Планировщику нужен доступ к тому же окружению, что и приложению. Отдельный брокер и Celery worker для этой задачи не требуются.

## Последствия

При штатной работе задержка запуска составляет до пяти минут плюс время обработки. Журнал с уникальным ключом защищает от повторных запусков команды. Ошибка отправки позволяет повторить попытку при следующем запуске в том же окне. Если процесс остановится после приёма письма почтовым сервером и до фиксации журнала в БД, возможна повторная доставка.
