## Что сделано
- `guard_files.py`: в режиме protect-tests разрешено создавать новые `tests/e2e/test_*.py`.
- `stop_check.py`: проверка откладывается, пока работает субагент; на выходе после 3 попыток хук предупреждает человека.
- `/task`, `e2e-tester`, `WORKFLOW.md`, `CLAUDE.md`: описано новое поведение; на шаге 2 тесты форматируются и проверяются ruff до коммита.

## Решения
| Вариант | Почему выбран или отклонён |
|---|---|
| Исключить весь `tests/e2e/` из protect-tests | Отклонён: implementer смог бы править e2e-тесты, которые test-writer зафиксировал как спецификацию |
| Снимать protect-tests перед шагом 5 | Отклонён: e2e-tester на это время получил бы доступ ко всем тестам |
| Маркер фазы red, который ставит `/task` | Отклонён: агент мог бы поставить его сам и отключить тесты в проверке |
| Поле `background_tasks` из входа Stop-хука | Выбран: список передаёт Claude Code, подделать его из проекта нельзя. Без этого поля (старая версия) хук работает как раньше |
