# T-002: Курсы и запись по коду

- Статус: todo
- Владелец: участник 2
- Зависимости: T-001
- Требования: FR-1.2, FR-1.3

## Цель
Преподаватель создаёт курс и получает код приглашения; студенты записываются по коду.

## Критерии приёмки
- [ ] **AC-1** Given преподаватель, When он создаёт курс (название, описание), Then курс сохраняется с уникальным 8-символьным `invite_code`, а преподаватель становится его владельцем.
- [ ] **AC-2** Given студент и верный код, When он вводит код на странице «Записаться», Then создаётся `Enrollment`, курс появляется в «Мои курсы».
- [ ] **AC-3** (негативный) Повторная запись не создаёт дубликат (UniqueConstraint), пользователь видит сообщение «Вы уже записаны».
- [ ] **AC-4** (негативный) Неверный код → ошибка формы, без 500.
- [ ] **AC-5** (права) Студент не может открыть страницу управления курсом (403), чужой преподаватель — тоже (403).
- [ ] **AC-6** Преподаватель видит список записанных студентов своего курса.

## Пользовательский сценарий
1. Преподаватель → «Создать курс» → видит код.
2. Студент → «Записаться» → вводит код → курс в списке.

## Технические заметки
- Модели `Course(owner, title, description, invite_code)`, `Enrollment(course, student, created_at)` — через `/model`.
- Генерация кода — `secrets`, с повтором при коллизии; тест на коллизию — через monkeypatch.
