# T-004: Рубрики — критерии, веса, шкалы

- Статус: todo
- Владелец: участник 2
- Зависимости: T-003
- Требования: FR-2.3, FR-2.4

## Цель
Преподаватель описывает, по чему и как оценивается задание.

## Критерии приёмки
- [ ] **AC-1** Given задание, When преподаватель добавляет критерии (название, описание, вес > 0) и уровни шкалы каждого критерия (балл, описание), Then рубрика сохраняется. Порядок критериев и уровней задаётся явно.
- [ ] **AC-2** (негативный) Критерий без уровней или с повторяющимися баллами → ошибка (`UniqueConstraint(criterion, points)`).
- [ ] **AC-3** Функция `max_score(rubric)` возвращает максимальный взвешенный балл; `normalized(scores)` — значение 0..1. Unit-тесты с несколькими весами.
- [ ] **AC-4** Рубрику можно скопировать из другого задания того же преподавателя (глубокая копия критериев и уровней).
- [ ] **AC-5** (негативный) После начала фазы `review` редактирование рубрики запрещено (сервис бросает ошибку, UI скрывает кнопки).
- [ ] **AC-6** Редактор рубрики на HTMX: добавление и удаление критерия без перезагрузки страницы.

## Пользовательский сценарий
1. Преподаватель → задание → «Рубрика» → добавляет 3 критерия по 4 уровня (0–3) → сохраняет → видит итоговую таблицу.

## Технические заметки
- Модели `Rubric(assignment 1:1)`, `Criterion(rubric, title, description, weight, order)`, `ScaleLevel(criterion, points, description)`.
- Подсчёт баллов — чистые функции в `apps/assignments/scoring.py` (без ORM на входе).
