# T-009: Рецензирование по рубрике: форма, автосохранение, анонимность

- Статус: done
- Владелец: участник 1
- Зависимости: T-004, T-008
- Требования: FR-5.1–FR-5.3, NFR-1

## Критерии приёмки

- [x] **AC-1** Студент открывает назначение по публичному коду из списка работ.
  Порядок стабилен для студента и задания, перемешан с помощью отдельного
  секрета. `AllocationRun.seed` в вычислении порядка не участвует.
- [x] **AC-2** Форма показывает критерии, уровни и описания замороженной рубрики.
  Черновик принимает неполные оценки и комментарии. HTMX сохраняет его после
  изменения поля. При отключённом JavaScript доступна кнопка сохранения.
- [x] **AC-3** Отправка требует уровень по всем критериям и общий комментарий. До дедлайна отправленную
  рецензию можно править без сброса времени отправки. После дедлайна доступен
  просмотр. Устаревшая версия формы и баллы из чужой шкалы отклоняются.
- [x] **AC-4** Каждый запрос проверяет роль, запись на курс и актуальное назначение.
  Чужой и несуществующий код дают одинаковый 404. Изменения принимаются
  только по POST с CSRF-защитой. Сохранение и переназначение используют одну
  блокировку задания. Начатую рецензию другому студенту не передают.
- [x] **AC-5** В HTML, URL и сообщениях нет данных об авторе, внутренних ID
  рецензии или seed. Назначенный рецензент скачивает файл только по публичному
  коду, с нейтральным именем и как вложение. Содержимое и метаданные файла
  сохраняются при выдаче, поэтому работу следует обезличить при подготовке.

## Пользовательский сценарий

Студент открывает назначенную работу, скачивает файл, выбирает уровень и пишет
комментарий. После автосохранения и обновления страницы поля на месте. Студент
заполняет рубрику, отправляет рецензию и может изменить её до дедлайна.
