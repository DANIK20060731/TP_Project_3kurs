# T-010: Автор видит рецензии и итоговую оценку

- Статус: done
- Владелец: участник 1
- Зависимости: T-009
- Требования: FR-5.4, FR-7.4

## Критерии приёмки

- [x] **AC-1** С дедлайна рецензирования автор и соавторы из курса видят
  отправленные рецензии своей работы по её публичному коду. Отображаются
  комментарии и оценки по критериям. Черновики исключены.
- [x] **AC-2** Автоматический итог — медиана нормализованных взвешенных баллов
  отправленных рецензий в процентах. При отсутствии рецензий автоматический итог
  отсутствует. Владелец задания после дедлайна может установить итог от 0 до 100
  процентов с точностью до сотых или очистить ручную оценку. Ручной итог имеет
  приоритет, включая 0 процентов. Запись защищена проверкой владения и CSRF.
- [x] **AC-3** До дедлайна студент не получает рецензии и итог. Чужая,
  недоступная по сроку и несуществующая работа возвращают одинаковый 404.
- [x] **AC-4** В HTML и контексте автора отсутствуют идентификаторы,
  логины, почта и время отправки рецензентов. Порядок вычисляется HMAC по
  работе и кодам рецензий отдельно от порядка и seed распределения.

## Пользовательский сценарий

После дедлайна автор открывает отзывы из страницы сдачи. Преподаватель
открывает список итоговых оценок со страницы задания, переопределяет итог
выбранной работы, а автор при следующем открытии видит новое значение.
