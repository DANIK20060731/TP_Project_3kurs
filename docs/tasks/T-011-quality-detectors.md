## Цель
Набор независимых детекторов «халтурных» рецензий в `apps/quality/detectors/` и размеченный eval-набор, который объективно измеряет их качество. Контракт — `apps/quality/CLAUDE.md`.

## Критерии приёмки
- [ ] **AC-1** `normalize(text)`: нижний регистр, ё→е, без пунктуации и лишних пробелов. Unit-тесты.
- [ ] **AC-2** `TooShort(min_words=30)`: флаг, если значимых слов меньше порога. Граница: ровно 30 слов → нет флага, 29 → флаг.
- [ ] **AC-3** `CopyPaste(threshold=0.8)`: Jaccard по 5-граммам слов; флаг на обеих рецензиях пары. Работает и внутри одного рецензента, и между разными. В `reason` указано, с какой рецензией совпадение и процент.
- [ ] **AC-4** `UniformScores`: все оценки одинаковые при ≥ 3 критериях → флаг; при < 3 критериях — нет.
- [ ] **AC-5** `TooFast(min_seconds=60)`: `seconds_spent < 60` → флаг; `None` → нет флага.
- [ ] **AC-6** `run_all(reviews, config)` возвращает объединённый список флагов, детекторы включаются и отключаются через конфиг.
- [ ] **AC-7** Eval: `tests/fixtures/reviews_eval.json` — не меньше 40 размеченных рецензий на русском (хорошие, короткие, копипаста с мелкими правками, одинаковые баллы). Тест считает precision/recall по каждому детектору: precision ≥ 0.9, recall ≥ 0.8.
- [ ] **AC-8** 300 рецензий по 150 слов — `CopyPaste` меньше 2 с (маркер `slow`), mypy strict, покрытие ≥ 95%, без импорта Django.

## Технические заметки
- Eval-набор пишет test-writer **до** реализации. Размеченные ожидания — часть спецификации, implementer их не меняет (protect-tests).
- CopyPaste: O(n²) по парам допустимо до ~300; при необходимости — MinHash (отметить в ADR).
