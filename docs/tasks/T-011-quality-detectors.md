# T-011: Ядро детекторов халтуры + eval-набор

- Статус: done
- Владелец: участник 1
- Зависимости: — (чистый Python, можно делать сразу)
- Требования: FR-6.1

## Цель
Набор независимых детекторов «халтурных» рецензий в `apps/quality/detectors/` и размеченный eval-набор, который объективно измеряет их качество. Контракт — `apps/quality/CLAUDE.md`.

## Критерии приёмки
- [x] **AC-1** `normalize(text)`: нижний регистр, ё→е, без пунктуации и лишних пробелов. Unit-тесты.
- [x] **AC-2** `TooShort(min_words=30)`: флаг, если значимых слов меньше порога. Граница: ровно 30 слов → нет флага, 29 → флаг.
- [x] **AC-3** `CopyPaste(threshold=0.6)`: Jaccard по 5-граммам слов; флаг на обеих рецензиях пары. Работает и внутри одного рецензента, и между разными. В `reason` указано, с какой рецензией совпадение и процент.
- [x] **AC-4** `UniformScores`: все оценки одинаковые при ≥ 3 критериях → флаг; при < 3 критериях — нет.
- [x] **AC-5** `TooFast(min_seconds=60)`: `seconds_spent < 60` → флаг; `None` → нет флага.
- [x] **AC-6** `run_all(reviews, config)` возвращает объединённый список флагов, детекторы включаются и отключаются через конфиг.
- [x] **AC-7** Eval: `tests/fixtures/reviews_eval.json` — не меньше 40 размеченных рецензий на русском (хорошие, короткие, копипаста с мелкими правками, одинаковые баллы). Тест считает precision/recall по каждому детектору: precision ≥ 0.9, recall ≥ 0.8.
- [x] **AC-8** 300 рецензий по 150 слов — `CopyPaste` меньше 2 с (маркер `slow`), mypy strict, покрытие ≥ 95%, без импорта Django.

## Технические заметки
- Eval-набор пишет test-writer **до** реализации. Размеченные ожидания — часть спецификации, implementer их не меняет (protect-tests).
- CopyPaste: O(n²) по парам допустимо до ~300; при необходимости — MinHash только как фильтр кандидатов: флаги и `score` считаются точным Jaccard (отметить в ADR).

## Решения
**Человек (2026-11-04): порог `CopyPaste` снижен с 0.8 до 0.6.** При 0.8 на eval-наборе recall был 0.65: две-три замены слов в тексте на 75 слов уже опускают Jaccard ниже порога, хотя задача требует ловить копипасту с мелкими правками. Порог проверен на наборе из 91 записи, включая трудные отрицательные примеры `hard-*` (общий шаблон рубрики, длинные цитаты из одной работы), добавленные после ревью:

| Порог | Precision | Recall | Ошибки |
|---|---|---|---|
| 0.5 | 0.90 | 0.90 | ложные: `hard-07`, `hard-08`; пропуск: `copy-h1`, `copy-h2` |
| 0.6 | 1.00 | 0.90 | пропуск: `copy-h1`, `copy-h2` |
| 0.7 | 1.00 | 0.80 | пропуск: `copy-b1`, `copy-b2`, `copy-h1`, `copy-h2` |

Ограничения для записки:
- Порог подобран на этом же наборе, а разметку делал агент, знавший о пороге, поэтому оценка оптимистична.
- Запас невелик: честная пара с длинными цитатами `hard-07`/`hard-08` имеет Jaccard 0.518, а настоящая копия `copy-h1`/`copy-h2` (около 5 разбросанных замен на 55 слов) только 0.397. Один порог не разделяет все пары.
- Набор не содержит отрицательных пар выше 0.6, а метрики одинаковы при порогах от 0.518 до 0.65. Честная пара «те же длинные цитаты плюс короткое мнение» будет помечена: при сокращении собственного текста `hard-07`/`hard-08` до одной фразы Jaccard становится 0.79.
- Поэтому флаг — повод для проверки преподавателем, а не вердикт.

**Координатор:**
1. `normalize` заменяет пунктуацию пробелом; цифры сохраняются.
2. `TooShort` считает слова после `normalize` без стоп-слов; пустой комментарий помечается.
3. Рецензия короче 5 слов не имеет 5-грамм: `CopyPaste` её не помечает, это случай для `TooShort`. На рецензию один флаг `copy_paste` с лучшим совпадением, при равенстве — наименьший `review_id`. Порог включительный. `Flag.score` — значение Jaccard.
4. `reason` не содержит `reviewer_id`.
5. `Flag.score` всегда в `[0, 1]`, `reason` непустой и на русском. У `copy_paste` `score` — значение Jaccard, у детекторов-правил всегда 1.0: нарушение правила установлено точно, а масштаб виден в `reason`. Значения `score` разных детекторов между собой не сравниваются. Отрицательное `seconds_spent` даёт флаг `too_fast`, в `reason` сказано, что время указано неверно.
6. `run_all`: отключённый детектор не даёт флагов, пустой вход даёт пустой список, результат не зависит от порядка рецензий, вход не изменяется. Порог `copy_paste` вне диапазона `0 < T <= 1` и неизвестное имя детектора дают `ValueError`; остальные диапазоны настроек проверяет форма задания в T-012.
7. В `reviewer_id` трёх записей eval-набора логин `krylova21` заменён на `sokolova21`, потому что он созвучен фамилии участника проекта. Это вымышленные логины; метки и тексты не менялись.
8. Тест скорости (AC-8) замеряет время в отдельном процессе без покрытия: внутри параллельного прогона с покрытием он падал примерно в половине случаев. Порог 2 с не менялся.
