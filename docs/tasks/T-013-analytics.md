# T-013: Дашборд: статистика, конфликты оценок, экспорт CSV

- Статус: done
- Владелец: участник 2
- Зависимости: T-009, T-010
- Требования: FR-7.1–FR-7.5

## Критерии приёмки

- [x] **AC-1** Владелец курса открывает дашборд со страницы задания. Счётчики сдачи считают записанных студентов, соавторов учитывают отдельно. Отправленные рецензии считаются выполненными, неотправленные становятся просроченными с дедлайна. Гистограмма считает работы с итогом по пяти диапазонам от 0 до 100%. Работы без оценки в гистограмму не входят.
- [x] **AC-2** При разбросе от 40 процентных пунктов между оценками отправленных рецензий работа помечается как конфликтная. Под работой раскрываются рецензии, включая баллы по критериям и комментарии. Черновики и аннулированные рецензии исключены из сравнения и расчёта оценок.
- [x] **AC-3** Рецензент помечается, если по двум и более работам его среднее абсолютное отклонение от медианы других рецензентов превышает 25 процентных пунктов. Работы без оценки другого рецензента не учитываются.
- [x] **AC-4** CSV доступен только владельцу курса. Одна строка на работу содержит публичный код, логины авторов и итоговый процент. Ручной итог из T-010, включая 0%, имеет приоритет над медианой. При отсутствии оценки поле пустое.
- [x] **AC-5** Порог конфликта, отклонения и распределение по диапазонам вычисляются чистыми функциями. Границы покрыты табличными unit-тестами.
