# T-014: Напоминания о дедлайнах

- Статус: in progress (напоминания о сдаче реализованы)
- Владелец: участник 2
- Зависимости: T-005, T-008
- Требования: FR-8.1–FR-8.3

## Критерии приёмки (черновик)
- [x] **AC-1 (сдача)** Команда `send_reminders` отправляет письма за 24 ч и за 2 ч до дедлайна студентам курса без сдачи. Сдавшие и соавторы исключаются.
- [ ] **AC-1 (рецензирование)** Напомнить до дедлайна тем, у кого есть незавершённые рецензии. Требуются назначения T-008 и данные T-009.
- [x] **AC-2 (сдача)** Идемпотентность: журнал `ReminderLog`, повторный запуск не шлёт дубли (тест с freezegun).
- [ ] **AC-3** Письма о назначении рецензий и о получении рецензий.
- [ ] **AC-4** (анонимность) В тексте писем нет имён авторов и рецензентов.
- [x] **AC-5** [ADR о запуске через cron](../adr/0005-reminder-scheduling.md).

## Запуск и поведение

После `make migrate` команда `uv run python manage.py send_reminders` использует почтовый backend из настроек Django. В dev по умолчанию письма выводятся в консоль.

- Команда отправляет 24-часовое письмо в интервале от 24 до 2 часов до дедлайна, исключая последние 2 часа. В последние 2 часа отправляется только 2-часовое письмо. В момент дедлайна и позже отправка прекращается.
- Получатели — активные студенты курса с email. В письме указываются курс, задание и дедлайн в часовом поясе проекта.
- Каждое из двух писем отправляется студенту один раз на задание, в том числе при переносе дедлайна. При ошибке доставки запись журнала откатывается, и команда завершится с ненулевым статусом после обработки остальных получателей.
