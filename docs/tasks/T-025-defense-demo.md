# T-025: Демо и оценка качества вопросов

- Статус: todo
- Владельцы (предложение): оба участника
- Зависимости: T-020, T-021, T-022, T-023, T-024
- Требования: [проект FR-9 и сценарии расширения §4](../SPEC-proposal-mini-defense.md), NFR-1, NFR-4

## Цель

Показать сценарий преподавателя и оценить пригодность вопросов на подготовленном наборе материалов.

## Критерии приёмки

- [ ] **AC-1** Given демонстрационный набор, When преподаватель проходит от сдачи и рецензий через предложения, ручной выбор и устную проверку, Then отдельно видны результат защиты и итог работы. Показать ручной режим без API и отдельную защиту рецензента.
- [ ] **AC-2** Given тестовые материалы и подставной поставщик, When выполняются автоматические проверки, Then проверяются структура, основания, права и e2e реализованных сценариев, без платных вызовов.
- [ ] **AC-3** Given вопросы из проведённой проверки, When преподаватель оценивает пригодность, Then фиксируются фактические числа принятых, изменённых и отклонённых предложений, причины и время подготовки. Проверка основания учитывается отдельно от полезности.
- [ ] **AC-4** Given согласованная отсрочка T-024, When показывают выполненный объём, Then сценарий рецензента явно указан как отложенный, а зависимости и критерии T-025 обновлены по согласованию. Исходное демо T-015 сохраняет свои сценарии.

## Пользовательский сценарий (e2e)

Сдача → рецензии → вопросы автору → утверждение → мини-защита → результат. Дополнительно ручной режим и, при включении T-024, обоснование рецензентом конкретного замечания.

## Технические заметки

Участник 2 ведёт демонстрацию и e2e; участник 1 готовит набор работ и рецензий и проверку качества вопросов. T-015 покрывает исходный цикл.

## Открытые вопросы

- Согласовать состав набора, порядок ручной оценки и объём показа, включая возможную отсрочку T-024.
